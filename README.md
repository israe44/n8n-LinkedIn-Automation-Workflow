# n8n LinkedIn Automation Workflow 

Imports an n8n workflow that:
- Generates LinkedIn topics
- Writes a post + image prompt without manual efforts
- Generates an image with OpenAI 
- Generates a visual using DALL°E
- Generates hashtags
- Publishes to LinkedIn automatically based on schedule trigger

## Setup
Create credentials in n8n:
- OpenAI (API key stored in n8n credentials)
- LinkedIn OAuth2

## Import
In n8n: Workflows → Import from File → select `workflow.json`

## Notes 
- This workflow would be perfect for content creators, marketers, entrepreneurs..
- Safe to use and modify
- API keys are not included
